# FAIRHIRE – AI Hiring Auditor

FAIRHIRE is an AI-powered hiring audit platform that detects bias in recruitment decisions.

## Features
- CSV upload
- Bias detection
- Gender/Region/Education fairness metrics
- Audit reports
- Candidate database
- PDF export
- Dashboard analytics
- MongoDB storage
- Authentication

## Tech Stack
Frontend:
- React
- TypeScript
- Vite
- TailwindCSS

Backend:
- Node.js
- Express.js
- MongoDB
- Mongoose

## Run

Frontend:
npm install
npm run dev

Backend:
npm install
npm run dev
